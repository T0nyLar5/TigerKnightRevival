# Tiger Knight revival: history

Timeline of the project from git history (2026-11-04 to 2026-11-06). Each entry is problem -> solution (commit). Short hash = commit. Add 1-3 lines after each milestone or user test result (see AGENT_GUIDE.md). Open problems are at the end.

## 2026-11-04: first contact, fake lobby, first battle launch
- Problem: game config files were encrypted and the server data unknown. Solution: cracked the Server.dat / langandplatform.dat cipher, added tools and notes (ab1d000).
- Problem: the client's real traffic was unknown. Solution: probe server that records TLS/Pomelo traffic, launchers and a Chinese guide (1fddc44); lobby protocol notes, decompiled Lua UI scripts and a PoClientDLL schema dumper (13fd321).
- Problem: no lobby, so the client cannot log in. Solution: fake lobby server v1 with handlers, selftest and guide (322ec3a).
- Problem: battle launch path unknown. Solution: launch analysis, UE3 .bin config cipher cracked, decrypted configs (cb0c305).
- Problem: client crashed in getSelfInfo (a scalar where the DLL indexes, so NULL deref). Solution: forbidmatch must be an object (c6113eb; see crash/analysis.md).
- Problem: loading screen stalled after entry. Solution: init-chain handlers; rank replies echo `nation` (5a9290d).
- Problem: no research on web/archived sources. Solution: web and Wayback research notes (ef9e6b1).
- Problem: bulk text work needs an outside LLM. Solution: tools/ask_llm.py for Gemini/DeepSeek (3e3a759).
- Problem: owner wanted everything unlocked. Solution: tools/unlock_all.py, push-delivered rank/science/soldier rows, tech-tree action routes (85ea129).
- Problem: battle exe does not start on its own. Solution: lobby push `gameStartup` (after joinMatch) launches it; setHelpPanel and max level 60 added (d2362f2). A direct launch fails because ParentWnd is required.
- Problem: real client sends subMode as a list. Solution: joinMatch accepts it (9d5bb95).
- Problem: map ids unknown. Solution: decoded from map.ani and the Loading table; gameMode 1/4/5 -> map 11/12/17 (a0213cb). 17 = training ground.
- Problem: no battle server. Solution: fake battle server with SyncClient frame loop and launcher (bdac045, 6530f91 phone-listener first).
- Problem: testing needed many manual steps. Solution: Ghidra decompile helper, log summarizer, one-click test/stop launchers (c9d08b1), agent guide, JDK 25 path and gitignore for portable tools (bff3035).
