# 使用說明：用 Cheat Engine 找出「誰把英雄傳送回起點」

目前狀況：用 V37 英雄可以走，但走超過約 11 公尺就會被拉回起點。
我們要找出「傳送回去的那一行程式」。做法：看英雄位置（Location.X）被誰寫入，
然後故意走遠讓它被拉回，記下「被拉回的瞬間」才出現的那一行。

整個過程不會改遊戲，只是「看」。約 10 分鐘。

## 事前準備
1. 用 `一鍵測試_選版本.bat` 選 **37**（V37），進到戰鬥，等英雄出現、倒數結束。
2. 先「不要」開 Cheat Engine。

## 步驟
1. 對 `英雄速度檢查.bat` 按右鍵，選「以系統管理員身分執行」，按鍵盤 **H**。
   畫面會顯示一排位址（Location.X 等），也存在 `server\logs\pawn_probe_last.txt`。視窗先不要關。
2. 對 Cheat Engine 按右鍵 -> 以系統管理員身分執行。左上角第一個按鈕（螢幕加放大鏡）
   -> 選 `Kingdom-Win64-Shipping.exe` -> Open。跳出問題一律選「否」。
3. 按 **Add Address Manually**，貼上 `Location.X` 的位址（不要 0x、不要空白），
   Type 選 **Float**，OK。
4. 在新加的那一列按右鍵 -> **Find out what writes to this address**。
   問要不要附加偵錯器就選 **Yes**。跳出的新視窗不要關。
5. 切回遊戲，**先只走幾步**（約 3 公尺內，不要被拉回）。
   回到 CE 視窗，**截圖一次**（要看得到每一列的 Count 次數）。這是「走遠之前」。
6. 回遊戲，**一直往同一方向走，超過 11 公尺**，直到你看到英雄被傳回起點，然後停下來。
7. 回到 CE 視窗，**再截圖一次**。這是「被拉回之後」。
8. 比較兩張截圖：
   - 一直在增加的大數字（幾百、幾千次）是「每格移動」的寫入，不是我們要的。
   - 我們要的是 **次數很小（例如 1 到 10 次）、而且只在被拉回之後才新出現或才增加** 的那一列。
9. 對那一列（和旁邊次數小的列）：點選 -> 按下面 **Show disassembler**，
   把最上方顯示的「模組+偏移」（例如 `Kingdom-Win64-Shipping.exe+123456`）和指令文字寫下來。
10. 若想更確定：重做一次步驟 6（再走遠被拉回一次），看那一列的次數是不是剛好多 1。

## 交給 Claude
貼給 Claude：
- 步驟 5 和 7 的兩張截圖（或複製文字）。
- 次數小的那幾列的「模組+偏移」和指令文字。
- `server\logs\pawn_probe_last.txt` 的內容。
- 遊戲有沒有出狀況（見下面警告）。
沒有任何一列出現也請告訴 Claude，這也是線索。

## 警告：遊戲被踢、當掉時請「立刻停止」
接上偵錯器時，遊戲可能偵測到並反應。如果出現：
- 突然回到登入畫面或被踢出；
- 遊戲當掉、視窗消失；
- CE 彈出「無法附加」或遊戲嚴重卡住；

請**不要重試很多次**：關掉 CE（先 Detach / Stop），用 `一鍵關閉.bat` 收乾淨，
然後回報 Claude「接上偵錯器後遊戲被踢 / 當掉」。

## 備案：改用 VEH 偵錯器（第一次失敗再試）
1. 完全關閉 CE 與遊戲，重新進戰鬥並重按 H（位址每次重開都會變）。
2. CE 選單 Edit -> Settings -> Debugger Options -> 選 **Use VEH debugger**，OK。
3. 從步驟 2 重做。還是被踢或當掉：停止並回報。

## 常見小問題
- Value 欄顯示 `??` 或一直是 0：位址貼錯或遊戲已重開，重新按 H。
- Value 是怪數字：Type 沒選 Float。
